# ASTRA AI Architecture

## 1. Overview
The AI Architecture in ASTRA bridges high-level natural language instruction (user prompts or voice commands) with low-level deterministic robot execution.

---

## 2. Execution Flow
```
[ User Input / Natural Language Prompt ]
                   │
                   ▼
       [ LLM Reasoning Agent ]
                   │
                   ▼
    [ Structured Mission JSON Plan ]
                   │
                   ▼
      [ Schema Validation Layer ]
                   │
                   ▼
        [ Mission Planner Node ]
                   │
                   ▼
   [ Safety Interlock Controller ]
                   │
                   ▼
      [ ROS 2 Control / Hardware ]
```

---

## 3. Strict Control Separation Principle
- **No Direct Motor Access**: The LLM agent is strictly forbidden from directly emitting low-level motor signals (`/cmd_vel`) or raw hardware register writes.
- **Deterministic Validation**: The LLM output MUST adhere strictly to `agent/schemas/mission_schema.json`.
- **Safety Interlock**: All actions generated by the LLM mission step planner pass through the Safety Controller before execution. If safety boundaries (battery, hazard clearance, restricted zone) are violated, the step is rejected or overridden with an emergency stop (`stop_rover`).
